ADR 0007 residue class -- a published minimum must satisfy
    minimum_mm + t_int == 0 (mod 250)

 t_int  residue   what it means
   100      150  <- what EVERY experiment on this map actually ran at
   120      130  <- what ticket 29 and ADR 0010 s3 both say was run. Nothing was.
   150      100  <- what ADR 0010 ships

==============================================================================
HALF ONE -- the linear minima, for a GRID-ALIGNED table. Invariant.
==============================================================================
`GRID*w - t >= GRID*min` gives `w >= min + ceil(t/GRID)`, and
ceil(t/250) is 1 for every t in (0, 250]. So 100, 120 and 150 impose
the SAME width and height bound -- but ONLY because every minimum in
this table is a whole number of grid units. See HALF THREE.

channel through which t_int can reach a solve at all.

harder. This is what the sweep has to measure.
